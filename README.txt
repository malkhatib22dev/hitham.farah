موقع دعوة زفاف تفاعلي — HTML + CSS + JavaScript

الملفات:
- index.html: بنية الصفحة ومحتوى الدعوة.
- style.css: التصميم والحركات والاستجابة للهاتف.
- script.js: المقدمة السينمائية، الانتقالات، قائمة الهاتف، مشاركة الرابط، وإضافة الموعد للتقويم.

التشغيل محليًا:
افتح index.html في المتصفح. يتطلب الاتصال بالإنترنت لتحميل الخطوط والصور من Unsplash وGoogle Fonts.

قبل النشر:
1) عدّل أسماء العروسين والتاريخ والمكان في index.html.
2) عدّل تاريخ التقويم في script.js ليطابق الموعد الحقيقي.
3) ارفع الملفات الثلاثة إلى مستودع GitHub.
4) من Settings > Pages اختر Deploy from a branch ثم main و /(root) واحفظ.
5) انتظر حتى يظهر رابط GitHub Pages.

ملاحظة: الصور والخطوط الخارجية تحتاج اتصال إنترنت. موعد المثال في التصميم هو 12 ديسمبر 2026 ويجب تعديله إذا كان مختلفًا.
